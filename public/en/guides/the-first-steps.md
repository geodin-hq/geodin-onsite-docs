# The First Steps

This guide walks you through creating a G1 Drilling Report in GeoDin Onsite — from initial project setup through to export.

## Initial Setup

Before creating a form, configure two areas under **Configuration**:

- **Integration tab** — select the geotechnical standard to apply to this project.
- **Project tab** — enter project-specific details (project number, client, client number, etc.).

### Project Number Requirements

Project numbers may only contain **letters, numbers, hyphens, and underscores**. The software stores forms in operating-system-dependent folders, so special characters such as asterisks are automatically converted to underscores.

## Creating the Report

1. Select **New Form** from the main menu.
2. Choose **G1 Drilling Report** from the list.

The G1 Drilling Report contains **eight pages** by default. Pages can be shown or hidden via **Show/Hide Pages** (menu under the logo) — for example, you can disable SPT or discontinuities pages and enable water levels, yielding a five-page form.

### Design Page

The **Design page** lets you configure borehole parameters either through the **Builder tool** or by entering values directly into fields.

- **Red fields** are mandatory.
- All other fields are optional and depend on project needs.

## Data Entry

When moving between rows, the system **automatically populates depth values**, reducing manual input.

## Validation and Export

You must validate the completed form before exporting:

1. Click the **Validate** button (tick icon).
2. The system highlights any missing or incorrect fields.
3. Once validation passes, open the **Export** menu.
4. Export the report as a **GeoDinML file**.

Progress can be saved at any time — validation is only required for export.

For importing the completed GeoDinML file into the main GeoDin system, refer to the GeoDin import documentation or the accompanying video tutorial.
